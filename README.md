# Marathi Calculator 🚀

A fully functional **Marathi-language calculator** for seamless numerical operations! 🎉

## 📌 Features:
✅ **Complete numerical calculations in Marathi** 🏆  
✅ **Simple and elegant UI** ✨  
✅ **Responsive Design for all devices** 📱💻  
✅ **Supports arithmetic operations ➕➖✖➗** 🔢  
✅ **Fast and accurate calculations** ✅

## 💻 Usage:
1️⃣ **Clone the repository:**  
```bash
 git clone https://github.com/YourUsername/Marathi-Calculator.git
```

2️⃣ **Open the file:**  
Open `index.html` in your browser and start using it!
